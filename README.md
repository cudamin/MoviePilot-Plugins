# 空间清理器（SpaceCleaner）

> MoviePilot V2 插件 · 版本 4.11.0 · 作者 [tafei](https://github.com/cudamin)

磁盘剩余空间不足时，自动删除**已经看完**的资源；同时内置一套面向 BT 动漫的 RSS 下载 / 洗版功能，两者共用同一份播放进度缓存。

- 空间清理：按「最早看完 / 最早入库」顺序删除，电视剧按季删，连带辅种、不同版本、媒体库文件与残留目录一并清理。
- BT动漫RSS下载/洗版：自动跳过已看完的剧集，只下载没看的；识别失败时可由种子文件名和智能助手（LLM）接管识别，并把识别词自动写回 MoviePilot。

---

## 一、准备工作：配置 Emby Webhook

插件的删除顺序与「是否看完」完全依赖媒体服务器上报的播放进度，**必须先配置 Webhook**。

在 EMBY 设置 → 通知 → 添加 Webhooks，Events 勾选**播放**，网址格式：

```
http://<MP容器IP地址>:3001/api/v1/webhook?token=<MP设置里的API令牌>
```

## 二、空间清理

### 工作方式

1. 按「执行周期」（cron）检查 MoviePilot 已配置目录所在磁盘的剩余空间。
2. 剩余百分比低于**删种触发阈值**时开始清理，每轮最多删除「单次删除资源数」个资源；开启**按目标百分比删除**后，会删一个资源、刷新一次真实剩余空间，直到达到**目标剩余百分比**为止。
3. 删除顺序：详情页手动标记的「优先删除」最前，其余按最早看完时间排序；开启**按媒体整理记录删除**后改为按整理记录中最早入库时间排序。
4. 电视剧以「季」为删除单元：整理记录中该季最后一集看完后，整季一起删除。电影按单片删除。
5. 每个删除单元会处理：下载器种子（含**辅种**，按所属下载器精确删除）→ 源文件 → 媒体库文件 → 整理记录 → 空目录 / 残留目录。
6. 开启**删除不同版本**后，会检索媒体整理记录，把同一集电视剧（tmdbid + 季 + 集）或同一部电影（tmdbid）的其他版本（不同分辨率、编码、字幕组、发布组）一并删除。

### 配置项

| 配置项 | 说明 |
| --- | --- |
| 启用插件 / 通知 | 总开关；通知会汇报本轮删除的资源、释放空间与残留目录 |
| 试运行模式 | 只在日志里列出将要删除的内容，不实际删除，**首次使用建议先开** |
| 立即运行一次 | 保存配置后立刻执行一轮检查 |
| 删种触发阈值（%） | 剩余空间低于此值开始删除 |
| 目标剩余百分比（%） | 配合「按目标百分比删除」使用 |
| 单次删除资源数 | 每次检查最多删除的资源数 |
| 标记已看进度阈值（%） | 播放进度达到此值即视为已观看 |
| 执行周期 | cron 表达式，默认 `0 */6 * * *`（每 6 小时） |
| 扫描下载器 | 删种时扫描的下载器，**留空扫描全部**；只做保种的下载器建议不要勾选 |
| 按目标百分比删除 | 持续删除直到剩余空间达标 |
| 删除不同版本 | 连带删除同集 / 同片的其他版本 |
| 按媒体整理记录删除 | 优先删除入库最早的已看资源 |

### 播放缓存管理（插件详情页）

- 磁盘空间概览：总空间、已用、剩余、剩余百分比。
- 播放缓存列表：支持按标题 / 状态 / 时间排序、关键字搜索、只看「已看完」、分页。
- 单条操作：`删除`（从缓存移除）、`已看`（手动标记看完）、`优先删除 / 取消优先`。
- 批量操作：`全部标记已看`、`清除全部`、`刷新`。

> 提示：只想立即释放空间时，可对目标剧集点「优先删除」再手动运行一次。

## 三、BT动漫RSS下载/洗版

<img width="262" height="93" alt="image" src="https://github.com/user-attachments/assets/a50a492b-7e25-4fbb-bfa0-2a42dc381e78" />

PT 下载的日番虽然发得快，但一般都是版权字幕，有时候翻译质量不太好；BT 字幕组的字幕质量相对更好，但更新慢甚至断更。洗版模式就是为了解决这些问题。

洗版模式的主要功能是对**没看完或者还没看**的日番进行洗版；RSS 链接可以填多个字幕组，插件会自动选择发布最早的版本，从而避免某个字幕组拖更或断更。

### 两种模式

- **普通模式**（洗版模式关闭）：新报文按过滤条件直接添加下载，已看完的剧集自动跳过。
- **洗版模式**：播放进度低于阈值或没有播放缓存时触发洗版；同一集的多个字幕组版本中，只下载**发布时间最早**的那个，已看完的集数不再洗版。

### 识别链路

```
RSS 报文标题  →  种子文件名（可选）  →  智能助手 LLM（可选）
```

- 识别缓存顺序：插件独立缓存 → MoviePilot 本地 TMDB 缓存 → TMDB API；API 识别失败的名称写入负缓存，避免重复请求。
- **种子文件名兜底识别**：报文识别失败、无集号或季号与播放缓存不一致时，下载种子用视频文件名再识别。
- **智能助手识别兜底**：以上手段仍失败时，交给「设定 - 智能助手」里配置的模型接管识别，结果按 TMDB ID 校验。
- **自动添加自定义识别词**：智能助手识别成功后，把校验通过的识别词写入「设定 - 自定义识别词」，下次相同命名由 MoviePilot 自行识别，不再消耗额度。可用「智能助手单轮调用上限」控制每轮刷新的调用次数。

### 配置项

| 配置项 | 说明 |
| --- | --- |
| 启用 / 通知 / 立即刷新RSS | RSS 板块总开关、下载通知、立即执行一次 |
| 洗版模式 | 只下载最早发布的版本，用于替换质量不佳的版权字幕 |
| 种子文件名兜底识别 | 报文识别不可靠时下载种子读文件名再识别 |
| 智能助手识别兜底 / 自动添加自定义识别词 / 单轮调用上限 | LLM 兜底识别与识别词自动落库 |
| 洗版播放进度阈值（%） | 低于该进度视为「没看完」，允许洗版 |
| 种子大小过滤（GB） | 形如 `1-10` |
| 执行周期 | cron 表达式，建议 10~30 分钟一次 |
| 下载器 | 指定 RSS 使用的下载器 |
| 优先级规则组 | 用 MoviePilot 的优先级规则组过滤种子，**留空不过滤** |
| 自定义保存路径 | 支持 `<storage>:<path>` 格式，留空用默认路径 |
| 代理重试 | 取种失败时用系统代理重试一次（磁链不重试） |
| RSS链接 | 支持多个，一行一个 |
| 包含（正则） | 例：`字幕组A|字幕组B`，`|` 表示「或」，不区分大小写 |
| 排除（正则） | 例：`合集|繁体|720p`，命中即跳过该报文 |

## 四、常见问题

**播放缓存一直是空的？**
Webhook 未生效。检查 Emby 通知里的 Events 是否勾选「播放」、URL 中的 IP 与 API 令牌是否正确。

**为什么删了种子但媒体库文件还在？**
下载器删除文件是异步的，插件会在同一删除单元里继续清理媒体库文件与残留目录；如仍残留，查看日志中该单元的「跳过删除目录」提示，通常是命中了受保护的配置目录。

**只想删下载器里的种子，不想动媒体库？**
本插件的定位是「释放空间」，删除单元会同时处理源文件与媒体库文件，不提供只删种子的模式。只做保种的下载器请不要勾进「扫描下载器」。

**RSS 一直识别不出某个字幕组的命名？**
开启「种子文件名兜底识别」；仍不行则开启「智能助手识别兜底」+「自动添加自定义识别词」，识别成功后会自动补一条窄匹配识别词。

**日志在哪里看？**
插件日志不在主日志里，路径为 `/config/logs/plugins/spacecleaner.log`。
