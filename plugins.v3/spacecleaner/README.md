# 空间清理&AniBT洗版（V3）

本说明对应 MoviePilot V3 插件 5.7.5；仓库首页的旧 V2 说明不代表本版本所有行为。

## 清理范围与失败恢复

- 「扫描下载器」留空时扫描全部；选择下载器后，只清理归属明确且在选中范围内的整理记录、种子和文件。归属未知、范围外或仍被范围外记录引用的文件会保留。
- Webhook 必须具有可确认的 TMDB 媒体身份；缺少身份的事件不会仅凭季集号匹配另一部作品。
- 每个单元先移除种子任务，再精确删除源文件和媒体库文件。删种失败就停止该单元；文件删除失败会保留整理记录和观看依据，下轮可重试，已经不存在的文件无需重复删除。
- 只有完整成功的单元计入成功数。单元失败或跳过不消耗成功数量，下一单元仍可继续；通知和历史不会把失败记为已删除。
- 残留目录只有明确的刮削元数据、字幕或系统垃圾时才清理。视频、音频、自定义媒体后缀、未知文件和子目录均会阻止整目录删除；因此可能比旧版多保留一些目录。
- 辅种不会仅凭「保存目录相同、体积相同」就认定。仍保留同名同体积、同内容路径同体积的识别；辅种只移除任务，不由下载器连带删文件。

## 停止与保存配置

保存配置前等待旧任务停止。若外部调用仍未返回，保留停止标志并拒绝切换到新运行配置，日志会提示稍后重新保存；旧任务结束后再保存即可恢复。旧调度回调不会借用新配置重新执行。停止期间未提交的 RSS 报文会撤回本轮去重标记，已成功下载的记录仍保留。

## RSS 选择和缓存

洗版先通过优先级规则组筛选，再在合格版本中选择同集最早发布者。真实下载失败继续按原有上限重试。

TMDB 非空季集清单缓存 6 小时，成功返回的空清单缓存 5 分钟；请求异常、模块不可用或无效响应不写入成功缓存。旧版没有时间戳的清单会在下次读取时刷新，重启后仍按保存时间判断是否过期。

5.7.4 的 AniBT 身份修复继续保留：只采用明确自动选中的作品，不合并不同作品的译名，明确 TMDB 提示优先于冲突旧映射。
