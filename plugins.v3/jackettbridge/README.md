# jackettBridge 1.4.0

将 Jackett 已配置的索引器接入 MoviePilot V3 搜索、站点浏览和订阅。

## 使用

1. 填写 MoviePilot 能访问的 Jackett 地址及 API Key，启用插件并同步一次。
2. 在插件内选择需要桥接的索引器；留空表示桥接全部。
3. 在 MoviePilot 搜索或订阅中选择对应的桥接站点。

管理密码为可选项，仅管理接口回退登录时需要。正常索引器发现使用 API Key。
桥接站点使用虚拟域名，站点管理中的普通网页连通性检测不适用。

**音乐订阅使用爬虫（spider）刷新模式。** 该模式由插件保留每条 Torznab 资源的媒体分类。
当前宿主通用 RSS 模式会丢失混合索引器的音乐分类，音乐资源不能正常进入音乐订阅缓存；
1.4.0 没有修改宿主 RSS 解析器，也不会自动改变用户的全局刷新设置。

## 1.4.0 更新

- 默认关闭的分身不再删除主实例站点；分身使用实例专属域名，主实例原域名及站点 ID 保留。
- 慢同步跨越关闭或重新配置时，旧结果不能写入新配置、快照或站点；新配置可以启动自己的同步。
- 适配当前宿主影视订阅与手动分页搜索的站点范围，空有效范围不再扩大为系统默认站点。
- 保留站点优先级、启用状态、代理、超时和用户附加配置；搜索跳过已禁用或删除的站点。
- 浏览时保留电影、剧集、音乐类型筛选；带时区发布时间先转本地时间。
- 合法空索引器目录清除旧记录；请求失败或错误 XML 保留原快照。

旧版分身与主实例共用域名，无法可靠还原这些记录原先属于谁。升级后分身重新同步生成独立站点，
需要为该分身重新选择搜索和订阅站点；旧共享记录由主实例管理，不自动转移到分身。

## 验证

插件仓回归位于 `tests/v3/jackettbridge/`，网络及持久化边界使用隔离替身。
覆盖慢同步重配、分身隔离、站点设置、真实宿主 `SearchSources.fetch` 的调用、空范围跨线程传递、
媒体筛选、时区和空目录。真实 Jackett 连通性及索引器行为需在使用环境中验证。
