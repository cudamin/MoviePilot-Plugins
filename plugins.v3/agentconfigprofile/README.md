# MP Switch

参考CC Switch制作，仓库地址https://github.com/farion1231/cc-switch?tab=readme-ov-file

MP Switch 为 MoviePilot V3 的智能助手管理供应商配置：保存当前配置、手动切换、
探测端点模型、按白名单导入，以及自动故障转移。插件 ID 保持 `agentconfigprofile`，
2.x 的配置、模板和历史记录继续使用，旧 `AgentConfigProfile` ID 的迁移逻辑保留。

## 三种模式

界面和实际行为参考 CC Switch：页签只浏览，点击“启用直连 / 启用路由 / 启用聚合”才切换生效模式。

- 直连：智能助手直接使用选定供应商，切换会写入系统 LLM 设置。
- 路由：系统连接插件在 127.0.0.1 上启动的网关，换供应商只改变路由指针。
  故障转移是独立开关，默认关闭；开启后按队列尝试，并使用熔断保护。
- 聚合：将加入成员的模型发布到一个目录。选择 `ccs-<永久key>/<模型>` 后固定调用对应供应商，
  普通模型请求使用默认供应商，整个聚合模式不做跨供应商故障转移。
  默认成员与正在使用的模型所属成员不能直接移除，请先换默认或选择另一个模型。

直连指针与代理路由指针分开保存，退出代理或停用插件时恢复直连供应商配置。
聚合 key 永不回收，已移除成员的旧模型 ID 明确报错，不会转发给另一家。
网关支持 OpenAI Chat Completions（包括流式响应）、模型目录、工具调用和用量。
先输出任何流式事件后不会换供应商重播，取消时释放流和客户端。

本机代理目前支持 OpenAI 兼容、DeepSeek 和 Anthropic 的 API Key 配置，使用已有宿主 SDK。
宿主到本机关闭系统代理，并统一使用 Chat Completions、本地搜索与可用成员的保守能力上限；
真实上游仍使用各自配置。内置助手通过本插件“选择模型”改变当前默认模型，
没有增加聊天页面中的每会话模型菜单。此限制不影响外部客户端从网关模型目录选择模型。

## 使用

1. 在插件配置页启用插件，保存当前智能助手配置，或通过模型探测导入配置。
2. 在数据详情页用“使用”选择直连配置，或在路由/聚合页执行该模式的操作，用“探活”检查连接；“更多操作”包含上移、下移、覆盖和删除。
   当前配置位于顶部，右侧为故障转移队列；窄窗口会自动上下排列。
   “模型发现”“运行记录”和“配置管理”按需展开。
3. 每个配置可加入或移出自动切换队列；移出后仍可手动应用和探活。
   旧配置默认加入队列，队列首项是自动恢复的首选配置。
4. 打开自动切换后，当前配置连续失败达到设置阈值时，严格按队列顺序尝试备用配置。
   已熔断的配置在 60 秒冷却期间跳过；冷却后仅放行一次恢复探测，连续成功两次后恢复。
   累计至少 10 次请求且错误率达到 60% 也会触发熔断。
5. User-Agent 可以手动输入，也可以选择随包复用的 CC Switch 预设；默认留空，
   选择后需启用全局参数并保存才应用。预设不保证任何供应商的服务权限。

定时探活按配置的 cron 运行；60 秒是最短冷却时间，并不会额外创建每分钟任务。
熔断记录属于进程内状态，保存配置或重载插件后重新累计。半开恢复尚未确认时，
不会把该配置交给智能助手即时接管。后台任务取消或配置变化时，旧结果会被忽略。

含凭据的模板仍按 MoviePilot 插件数据机制保存 API Key。关闭“模板包含 API Key”后，
只有供应商与端点一致才允许复用当前密钥。页面不回显模型 API Key，探活异常会清洗密钥。
本插件操作 MoviePilot 内置智能助手配置，不修改 CC Switch、Claude Code 或 Codex 的本机文件。

## 源码组织与复用

- `__init__.py`：插件身份、生命周期、旧 ID 迁移和宿主 API/事件入口。
- `profiles.py`：快照、写入校验、队列成员和排序。
- `health.py`：探活、并发任务、熔断集成和过期结果处理。
- `circuit_breaker.py`：依据 CC Switch Rust 源码移植的线程安全状态机。
- `discovery.py`：模型发现与白名单导入。
- `views.py`：宿主供应商工作台及仪表盘。
- `forms.py`：四分区设置表单，保留原配置键与默认值。
- `page_style.py`：跟随亮暗主题和容器宽度的局部样式。
- `modes.py`：直连/路由/聚合状态、永久模型身份和客户端配置投影。
- `gateway.py`、`protocol.py`：本机网关、流式故障转移边界和协议适配。
- `presets.py` 与 `third_party/cc-switch/`：直接复用的预设资源、MIT 许可和来源说明。

参考提交、对应源文件及适配差异见 `third_party/cc-switch/README.md`。

## 验证

在插件仓根目录，使用安装了 MoviePilot V3 依赖的隔离测试解释器：

```powershell
python -m pytest tests/v3/agentconfigprofile -q
python -m ruff check plugins.v3/agentconfigprofile tests/v3/agentconfigprofile --select E4,E7,E9,F,I
```

测试使用临时 CONFIG_DIR、内存插件存储和网络守卫，不请求真实模型、不修改真实账户配置。
复制安装时必须复制整个 `agentconfigprofile` 目录（包括 `third_party`），之后重载插件。
